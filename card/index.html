③ 전화할 때 이 영상이 나오게 하기

저장한 명함 동영상을 이 연락처의 통화 배경으로 지정하면, 지승호 고문에게 전화를 걸고 받을 때 통화 화면에 이 영상이 재생됩니다. 통신사 부가서비스 가입이 필요 없어요.

  1. 연락처 앱에서 ‘지승호’를 엽니다.
  2. 편집 → 아래쪽 더보기 → 통화 배경을 누릅니다.
  3. 오른쪽 위 ＋를 눌러 갤러리에서 AOC_지승호_고문_명함 동영상을 고릅니다.
  4. 설정(또는 저장)을 누르면 끝! 이제 통화 화면에 영상이 나옵니다.
  5. 메뉴가 안 보이면 전화 앱 → ⋮ → 설정 → 통화 배경에서 설정하거나, 설정 앱에서 ‘통화 배경’을 검색하세요. 메뉴 이름은 기종·One UI 버전에 따라 조금 다를 수 있어요.
  1. 아이폰은 통화 화면에 동영상을 넣는 기능이 없습니다(애플 정책).
  2. 대신 연락처에 들어간 얼굴 사진이 통화 화면에 크게 나옵니다. 연락처 → 지승호 → 편집 → 사진에서 ‘포스터’로 크게 설정할 수 있어요.
  3. 명함 동영상은 사진첩에 저장해 두고 언제든 다시 볼 수 있습니다.
  1. LG·샤오미 등은 기종마다 메뉴가 다릅니다. 연락처 편집 또는 전화 앱 설정에서 ‘통화 배경’, ‘통화 화면’, ‘동영상 벨소리’ 항목을 찾아 저장한 동영상을 고르세요.
  2. 해당 기능이 없는 기종은 연락처 사진이 통화 화면에 표시됩니다.
