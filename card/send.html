📤 동영상 명함 보내기

이 페이지는 고문님 전용입니다. 아래 버튼을 누르면 명함 동영상 파일 1개를 카톡이나 문자로 바로 보낼 수 있어요.

⬇ 카톡용 파일 내려받기 (720p, 2.2MB) ⬇ 문자용 파일 내려받기 (0.9MB) ⬇ 명함 사진 내려받기
보내는 방법
① 카톡으로 보내기 → 공유 창에서 카카오톡 → 받을 사람 선택 → 보내기
② 문자로 보내기 → 공유 창에서 메시지 → 받을 사람 선택 → 보내기
공유 창이 안 뜨는 휴대폰은 파일 내려받기 후, 카톡 ＋ → 앨범 또는 문자 ＋ → 갤러리에서 보내세요.
